Ahmedabad 2047 - Exhibition Game
================================

Files
- index.html          Open this file in Chrome, Edge or Safari (or host the folder on any web server).
- videos/             One film per scenario. Keep these names exactly as they are:
    manufacturing-led.mp4     (Manufacturing-led)
    productivity-led.mp4      (Productivity-led)
    globally-connected.mp4    (Globally Connected)

Notes
- The game is a single page: it needs an internet connection for the React, Tailwind and QR code libraries.
- Visitors cannot upload or replace videos. The winning scenario's film plays on the results screen.
- To change the phone link, use "Set game link" on the results or start screen. The link is saved in that browser only.
